Codex × Feishu

把 Codex 带到飞书里。

任务状态卡片、权限阶段、完成提醒，以及从飞书继续向原 Codex session 发送指令。每位用户在自己的飞书租户创建并绑定机器人，凭据保存在本机。

三步开始

npx codex-feishu-hook-bridge setup
npx codex-feishu-hook-bridge install
npx codex-feishu-hook-bridge doctor

setup 会打开飞书授权页面。确认后，官方 SDK 会为你的租户创建应用并返回本机所需凭据；不需要把 App Secret 发给项目维护者。

你会得到什么

  • 一轮只保留一张状态卡片：收到指令 → 等待授权 → 本轮完成。
  • 完成时通过飞书应用内加急触发提醒。
  • 回复自己的 prompt 消息时显示 Get / DONE reaction。
  • 追加指令继续进入原来的 Codex session。
  • macOS 登录后自动启动 listener。

安全边界

App Secret 写入 ~/.codex/feishu-bridge/config.env，权限为 0600。不要把这个文件提交到 GitHub。这个版本采用本地优先模式；如果未来提供集中式 SaaS，需要另行设计商店应用、租户绑定和云端密钥隔离。
